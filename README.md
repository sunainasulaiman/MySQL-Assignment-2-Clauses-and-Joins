# MySQL-Assignment-2-Clauses-and-Joins
MySQL Assignment 2 – Querying Data
📌 Project Overview

This assignment focuses on querying and analyzing employee data using MySQL.

It continues from the previous assignment, where the database and tables were created with required constraints. The employee data was then inserted using DML commands.

🎯 Objectives

The main objective of this assignment is to practice:

Retrieving unique values using DISTINCT
Using column aliases with AS
Filtering data using WHERE
Using comparison and logical operators
Sorting data using ORDER BY
Limiting query results using LIMIT
Using aggregate functions
Grouping data using GROUP BY
Filtering grouped data using HAVING
Performing different types of JOIN


Through this assignment, I practiced writing SQL queries for filtering, sorting, grouping, aggregation, and joining tables. It helped me understand how SQL can be used to retrieve meaningful information from a relational database.
